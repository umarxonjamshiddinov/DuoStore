# DUO STORE

**Сайт:** [Открыть DUO STORE](https://umarxonjamshiddinov.github.io/DuoStore/)

Магазин одежды и аксессуаров. Клиентская часть работает без сборки: каталог, поиск, избранное, выбор размера, корзина и оформление без регистрации.

Запуск из папки проекта:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Откройте [127.0.0.1:8000](http://127.0.0.1:8000/). Каталог использует публичные данные Supabase и переключается на локальную копию при ошибке подключения. Резервный каталог хранится в `js/store-data.js`, настройки Supabase — в `js/supabaseClient.js`.

При онлайн-оформлении витрина проверяет товары и цены и сохраняет заказ в Supabase. Для ручного оформления покупатель может открыть или скопировать черновик заявки в Telegram. Оплата и условия доставки согласуются с менеджером.

Регистрации и входа для покупателей нет. Для проверки статуса нужны номер заказа и телефон, указанный при оформлении. SMS-провайдер подключать не нужно. Вход для сотрудников работает отдельно в админке.

Чтобы повторить автоматические проверки в Windows, оставьте сервер запущенным и выполните в другом терминале:

```powershell
npm install --prefix "$env:TEMP/duo-store-qa" playwright
$env:NODE_PATH = "$env:TEMP/duo-store-qa/node_modules"
$env:DUO_CHROME = 'C:/Program Files/Google/Chrome/Application/chrome.exe'
node --test tests/storefront.spec.cjs
```

Тесты подменяют ответы Supabase и не создают реальные заказы. Подробности проверки и шаги перед публикацией — в [отчёте по MVP](MVP_REPORT.md).
